# ElectroLab DZ ⚡

مختبر عربي تفاعلي لدوائر التيار المستمر، مبني بـ React وTypeScript وVite. الحسابات محلية، دون API أو حساب مستخدم.

## التشغيل

يتطلب Node.js 22.6 أو أحدث (يفضل 22 LTS أو 24).

```sh
npm ci
npm run dev
```

افتح عنوان Vite الذي يظهر في الطرفية. للتحقق:

```sh
npm test
npm run build
npm run preview
```

## تجربة المختبر

1. تبدأ المساحة بدارة توالٍ جاهزة: بطارية 12V ومقاومتان 100Ω و200Ω.
2. اضغط «تشغيل المحاكاة»، وحدد كل عنصر لعرض قراءاته: التيار 0.04A والجهدان 4V و8V.
3. اسحب جسم العنصر لتحريكه. اضغط دائرة طرف، ثم طرف عنصر آخر لإضافة سلك. الأسلاك تعيد رسم مسارها تلقائيًا.
4. أضف عناصر من المكتبة، وعدّل القيم من لوحة الخصائص. يمكنك تدوير العناصر وحذفها؛ حذف العنصر يحذف أسلاكه أيضًا.
5. اضغط سلكًا لتحديده ثم احذفه من لوحة الخصائص. حذف سلك الرجوع يكشف الدارة المفتوحة؛ توصيل قطبي البطارية مباشرة يكشف القصر.
6. جرّب التوازي والمصباح من بطاقات التجارب. **تحميل تجربة يستبدل الدارة الحالية**؛ احفظها أولًا.
7. زر الحفظ يخزّن في المتصفح وينزّل JSON. زر المجلد يسترجع ملفًا، وزر الرجوع يستعيد آخر حفظ محلي. لا تضع بيانات حساسة في ملفات الدوائر.

## النموذج الكهربائي

تحليل العقد المعدل (MNA) يحل نظام معادلات قانون كيرشوف للتيار والجهد مع مصادر جهد مثالية. الأسلاك والمفاتيح المغلقة عقد متحدة، والمفتاح المفتوح فرع مفصول. لكل جزيرة كهربائية مرجع مستقل. قيم التيار من الطرف الأول (الأيسر قبل التدوير) إلى الثاني، والجهد V₀−V₁؛ قدرة البطارية السالبة تعني تزويد الطاقة.

- المقاومة والمصباح: مقاومة خطية ثابتة، لا نموذج حراري أو زمن انتقالي.
- الأمبيرمتر: مقاومة داخلية 0.001Ω؛ يوصّل على التوالي.
- الفولتمتر: مثالي، لا يسحب تيارًا؛ يوصّل على التوازي. القياس بين جزيرتين منفصلتين غير معرّف.
- القصر المثالي على المصدر يُرفض. مصادر الجهد المتعارضة أو الزائدة تنتج رسالة تشخيص بدل أرقام زائفة.
- فحص الدارة المفتوحة يعرض تنبيهًا عند انعدام التيار الكلي؛ ليس فحصًا شاملًا لكل فرع جزئي غير موصول.
- كل تعديل يلغي النتائج القديمة؛ أعد تشغيل المحاكاة بعد التعديل.
- لا محاكاة AC أو محركات أو PLC في هذه المرحلة.

تغطي الاختبارات التوالي، التوازي، توازن القدرة، القصر، القطع، الأسلاك غير الصالحة، المفتاح، والفولتمتر.

## النشر المجاني على GitHub Pages

أُضيف workflow في `.github/workflows/deploy.yml` يثبّت الحزم بملف القفل، ويختبر ويبني وينشر مجلد `dist`.

1. ارفع الملفات إلى فرع `main`.
2. من إعدادات المستودع: **Settings → Pages → Source → GitHub Actions**.
3. شغّل workflow أو ادفع تغييرًا إلى `main`؛ يظهر رابط الموقع في مخرجات النشر.

إعداد Vite يستخدم `base: '/electrolab-dz/'` لتوافق مسار المستودع. لم يُنفّذ نشر فعلي تلقائيًا. خط IBM Plex Sans Arabic يُحمّل اختياريًا من Google Fonts؛ عند انقطاع الإنترنت يستخدم الموقع Tahoma/Arial وتبقى المحاكاة تعمل.


## المعاينة من حاسوبك دون أدوات برمجة

لا توفر بيئة الإعداد رابط معاينة عامًا. خادم التطوير يستمع على `0.0.0.0:4173`، لكن هذا لا ينشئ رابط إنترنت عامًا.

للنشر من واجهة GitHub:

1. احفظ ملفات العمل في فرع `main` بواسطة زر إنشاء Pull Request في واجهة المهمة إن توفر، ثم افتح الطلب في GitHub وادمجه. إذا نزّلت المشروع كملفات، افتح المستودع في GitHub واختر **Add file → Upload files** وارفع ملفات المشروع ومجلد `src` دون `node_modules` و`dist`.
2. تأكد من وجود `.github/workflows/deploy.yml` في المستودع. عند رفع الملفات يدويًا، يمكنك إنشاؤه عبر **Add file → Create new file** ونسخ محتواه من المشروع، لأن بعض أنظمة الملفات تخفي مجلد `.github`.
3. افتح **Settings → Pages** واختر **GitHub Actions** ضمن **Build and deployment → Source**.
4. افتح **Actions → Deploy ElectroLab DZ → Run workflow**، اختر `main` ثم **Run workflow**.
5. انتظر ظهور علامة النجاح الخضراء. افتح التشغيل ثم اضغط رابط **github-pages** في قسم النشر.

العنوان المتوقع بعد نجاح النشر هو `https://zakkoussama1-wq.github.io/electrolab-dz/`. لا يصبح رابطًا منشورًا بمجرد وجود ملفات workflow. إذا كان المستودع خاصًا ولا تسمح خطتك بـ Pages، اجعله عامًا فقط إذا كنت موافقًا على إتاحة شيفرته للجميع.

## المرحلة التعليمية الأولى

أضيفت المراجع القابلة للعكس، والعقد والفروع والحلقات المستقلة، وجدول كل القراءات، ولوحة «حل الدارة خطوة بخطوة». اضغط علامة القطبية أو السهم أو استخدم أزرار الخصائص، ثم قارن القراءات مع المعادلات. راجع [تقرير المرحلة الأولى](PHASE1.md) للنموذج الرياضي والاختبارات وحدود الدعم. ملفات PDF الجامعية لم تُزوّد بعد؛ لا أمثلة منسوبة إليها.

## المعادلات الأكاديمية

تستخدم لوحة الحل KaTeX بكسور عمودية ورموز مرتبطة بالرسم وسبع خطوات مشتقة من الدارة الفعلية. اختر قانونًا ثم انقر أرقام الخطوات أو «الخطوة التالية». يمكن نسخ LaTeX وطباعة الدارة والخطوات كلها إلى PDF من المتصفح. التفاصيل والحدود في [توثيق العرض الرياضي](MATH_PRESENTATION.md).
