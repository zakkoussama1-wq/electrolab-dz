المرجع التعليمي الحالي هو `Chapter 1.pdf` و`Series 1.pdf` المرفقان من المستخدم فقط. راجع [تقرير التدقيق وخطة التنفيذ](COURSE_AUDIT.md)، و[سجل التقدم الأساسي](COURSE_PROGRESS.md)، و[فهرس الصفحات والرسومات](docs/COURSE_FIGURES.md). لا تعني الأمثلة العامة القديمة أنها مطابقة لتمارين المقرر؛ نقل المحتوى خارج المقرر إلى قسم اختياري يبقى مؤجلًا؛ تنفيذ المرحلة المعتمدة يقتصر حاليًا على Exercise 1.

صفحتا «تقدم تطوير المختبر» و«حول المختبر» متاحتان من شريط التنقل. الأولى تقرأ الحالات من `COURSE_PROGRESS.md` مباشرة، ولا توجد نسب نجاح افتراضية. Exercise 1 والأمثلة 2.2 و2.5 و2.8 اجتازت الاختبارات العلمية والتفاعلية؛ بقية دارات PDF تحتفظ بحالاتها المسجلة.

مختبر عربي تفاعلي موحد لدوائر DC وRC من الرتبة الأولى، مبني بـ React وTypeScript وVite. الحسابات محلية، دون API أو حساب مستخدم.

## المختبر الموحد الحالي

ارسم مباشرة في مساحة واحدة بمكتبة العناصر السبعة؛ يختار الموقع DC أو RC تلقائيًا بحسب عناصر الدارة وتوصيلاتها. أضيف منحنى الطاقة وخطوات أكاديمية من عشر مراحل ووضع امتحان موحد. راجع [دليل الدمج والتوافق وحدود التصحيح](UNIFIED_LAB.md).

## تجربة المختبر

1. تبدأ المساحة بدارة توالٍ جاهزة: بطارية 12V ومقاومتان 100Ω و200Ω.
2. اضغط «تشغيل المحاكاة»، وحدد كل عنصر لعرض قراءاته: التيار 0.04A والجهدان 4V و8V.
3. اسحب جسم العنصر لتحريكه. اضغط دائرة طرف، ثم طرف عنصر آخر لإضافة سلك. الأسلاك تعيد رسم مسارها تلقائيًا.
4. أضف عناصر من المكتبة، وعدّل القيم من لوحة الخصائص. يمكنك تدوير العناصر وحذفها؛ حذف العنصر يحذف أسلاكه أيضًا.
5. اضغط سلكًا لتحديده ثم احذفه من لوحة الخصائص. حذف سلك الرجوع يكشف الدارة المفتوحة؛ توصيل قطبي البطارية مباشرة يكشف القصر.
6. جرّب التوازي والمصباح من بطاقات التجارب. **تحميل تجربة يستبدل الدارة الحالية**؛ احفظها أولًا.
7. زر الحفظ يخزّن في المتصفح وينزّل JSON. زر المجلد يسترجع ملفًا، وزر الرجوع يستعيد آخر حفظ محلي. لا تضع بيانات حساسة في ملفات الدوائر.

## النموذج الكهربائي

تحليل العقد المعدل (MNA) يحل نظام معادلات قانون كيرشوف للتيار والجهد مع مصادر جهد مثالية. الأسلاك عقد متحدة، ويُحل المفتاح المغلق كفرع مصدر صفري الجهد لحساب تياره، والمفتاح المفتوح فرع مفصول. لكل جزيرة كهربائية مرجع مستقل. قيم التيار من الطرف الأول (الأيسر قبل التدوير) إلى الثاني، والجهد V₀−V₁؛ قدرة البطارية السالبة تعني تزويد الطاقة.

- المقاومة والمصباح: مقاومة خطية ثابتة، لا نموذج حراري أو زمن انتقالي.
- الأمبيرمتر: مقاومة داخلية 0.001Ω؛ يوصّل على التوالي.
- الفولتمتر: مثالي، لا يسحب تيارًا؛ يوصّل على التوازي. القياس بين جزيرتين منفصلتين غير معرّف.
- القصر المثالي على المصدر يُرفض. مصادر الجهد المتعارضة أو الزائدة تنتج رسالة تشخيص بدل أرقام زائفة.
- فحص الدارة المفتوحة يعرض تنبيهًا عند انعدام التيار الكلي؛ ليس فحصًا شاملًا لكل فرع جزئي غير موصول.
- كل تعديل يلغي النتائج القديمة؛ أعد تشغيل المحاكاة بعد التعديل.
- لا محاكاة AC أو محركات أو PLC في هذه المرحلة.

تغطي الاختبارات التوالي، التوازي، توازن القدرة، القصر، القطع، الأسلاك غير الصالحة، المفتاح، والفولتمتر.

## النشر المجاني على GitHub Pages

أُضيف workflow في `.github/workflows/deploy.yml` يثبّت الحزم بملف القفل، ويختبر ويبني وينشر مجلد `dist`.

1. ارفع الملفات إلى فرع `main`.
2. من إعدادات المستودع: **Settings → Pages → Source → GitHub Actions**.
3. شغّل workflow أو ادفع تغييرًا إلى `main`؛ يظهر رابط الموقع في مخرجات النشر.

إعداد Vite يستخدم `base: '/electrolab-dz/'` لتوافق مسار المستودع. لم يُنفّذ نشر فعلي تلقائيًا. خط IBM Plex Sans Arabic يُحمّل اختياريًا من Google Fonts؛ عند انقطاع الإنترنت يستخدم الموقع Tahoma/Arial وتبقى المحاكاة تعمل.


## المعاينة من حاسوبك دون أدوات برمجة

لا توفر بيئة الإعداد رابط معاينة عامًا. خادم التطوير يستمع على `0.0.0.0:4173`، لكن هذا لا ينشئ رابط إنترنت عامًا.

للنشر من واجهة GitHub:

1. احفظ ملفات العمل في فرع `main` بواسطة زر إنشاء Pull Request في واجهة المهمة إن توفر، ثم افتح الطلب في GitHub وادمجه. إذا نزّلت المشروع كملفات، افتح المستودع في GitHub واختر **Add file → Upload files** وارفع ملفات المشروع ومجلد `src` دون `node_modules` و`dist`.
2. تأكد من وجود `.github/workflows/deploy.yml` في المستودع. عند رفع الملفات يدويًا، يمكنك إنشاؤه عبر **Add file → Create new file** ونسخ محتواه من المشروع، لأن بعض أنظمة الملفات تخفي مجلد `.github`.
3. افتح **Settings → Pages** واختر **GitHub Actions** ضمن **Build and deployment → Source**.
4. افتح **Actions → Deploy ElectroLab DZ → Run workflow**، اختر `main` ثم **Run workflow**.
5. انتظر ظهور علامة النجاح الخضراء. افتح التشغيل ثم اضغط رابط **github-pages** في قسم النشر.

العنوان المتوقع بعد نجاح النشر هو `https://zakkoussama1-wq.github.io/electrolab-dz/`. لا يصبح رابطًا منشورًا بمجرد وجود ملفات workflow. إذا كان المستودع خاصًا ولا تسمح خطتك بـ Pages، اجعله عامًا فقط إذا كنت موافقًا على إتاحة شيفرته للجميع.

## المعادلات الأكاديمية

تستخدم لوحة الحل KaTeX بكسور عمودية ورموز مرتبطة بالرسم وسبع خطوات مشتقة من الدارة الفعلية. اختر قانونًا ثم انقر أرقام الخطوات أو «الخطوة التالية». يمكن نسخ LaTeX وطباعة الدارة والخطوات كلها إلى PDF من المتصفح. التفاصيل والحدود في [توثيق العرض الرياضي](MATH_PRESENTATION.md).

## مختبر RC — المرحلة الثانية

حمّل تجربة RC من بطاقات التجارب أو أضف مكثفًا إلى المساحة لتركيب دارة ذات مكثف واحد، وتشغيل الشحن أو التفريغ مع منحنيات تفاعلية وشرح KaTeX ووضع امتحان. يتضمن خمس تجارب ومؤشر زمن وتحويل وحدات السعة وحفظ JSON. فتح المفتاح يحافظ على جهد المكثف إذا لم يوجد مسار تفريغ. راجع [دليل RC والنموذج العلمي والحدود](RC_LAB.md). تبقى حسابات DC وميزاتها ضمن المساحة الموحدة.


## المرحلة الأولى المعتمدة: Exercise 1

اضغط «فتح دائرة Exercise 1» من لوحة التمرين، ثم «تشغيل المحاكاة». جرّب الإجابات أولًا واضغط «تصحيح المحاولة»، أو اطلب «إظهار الحل خطوة بخطوة». يمكنك تغيير القيم والتحريك والتدوير وعكس المراجع؛ أعد التشغيل بعد تعديل الدارة. في وضع الامتحان يبقى التصحيح التفصيلي مخفيًا حتى طلب كشف الحل العام.

الدائرة من Series 1.pdf، الصفحة1، Figure1. نتائج الأسهم الأصلية: I₁=−5A، I₂=8A، I₃=3A. يوضح الموقع فرق الفروع العنصرية عن المسارات الأساسية والحلقات البسيطة عن المعادلات المستقلة. راجع [دليل التحقق والقيود](docs/EXERCISE_1_VALIDATION.md).

```sh
npm test
npm run build
```

اختبار التفاعل اختياري ويتطلب Chromium وPlaywright Core مثبتين خارج المشروع، ثم تشغيل Vite في نافذة أخرى:

```sh
npm install --prefix /tmp/electrolab-browser playwright-core
PLAYWRIGHT_MODULE=/tmp/electrolab-browser/node_modules/playwright-core node scripts/check-exercise1.cjs
```

يمكن ضبط `APP_URL` لعنوان المعاينة، و`BROWSER_PATH` لمسار Chromium. لا يحتاج الموقع نفسه إلى المتصفح الآلي أو خادم خلفي. يبقى نشر GitHub Pages من `dist` وبالمسار `/electrolab-dz/`.


## الدروس والتجارب — واجهة الطالب

افتح «الدروس والتجارب» من شريط التنقل. تتوفر خمسة دروس: أوم، كيرشوف للتيار والجهد، التوالي ومقسم الجهد، والتوازي ومقسم التيار. الأمثلة من Chapter 1.pdf (2.2 و2.5 و2.8) وSeries 1.pdf (Exercise 1)، مع صفحاتها ورسومها ومعطياتها الأصلية.

يحتوي كل درس على التعريف والفكرة والأهداف والقانون وتفسير الرموز، ورسم فعلي مرتبط بالمعادلات، وخطوات الحل والنتائج والتحقق. يمكن تعديل القيم والأسهم والأقطاب، وإخفاء التصحيح للمحاولة، ونقل الدارة إلى مساحة العمل. تفاصيل التطوير والاختبارات متاحة منفصلة في «حالة تطوير المختبر · للمطور»؛ التجارب القديمة محفوظة في قسم اختياري داخل المختبر.

فحص الواجهة البصري والتفاعلي (يتطلب تشغيل Vite وChromium كما في التعليمات السابقة):

```sh
PLAYWRIGHT_MODULE=/tmp/electrolab-browser/node_modules/playwright-core node scripts/check-student-ui.cjs
```

ينتج20 لقطة في `/tmp/student-visual` ويفحص RTL/LTR والمحاذاة والإبراز والمحاولة والتعديل ونقل الدارة. تفاصيل الحدود والتغطية في [تقرير واجهة الطالب](docs/STUDENT_EXPERIENCE.md). تبقى النظريات التي لم يكتمل تحليلها دون زر تشغيل.

### اختبار التعافي عند إضافة مكثفات

يمكن رسم وحفظ أكثر من مكثف؛ المحاكاة الزمنية الحالية لمكثف واحد فقط. عند تجاوز هذا الحد تبقى مساحة العمل متاحة وتظهر رسالة تفسيرية، وعند إزالة المكثفات الزائدة تعود المحاكاة المدعومة.

```sh
PLAYWRIGHT_MODULE=/tmp/electrolab-browser/node_modules/playwright-core node scripts/check-capacitor-recovery.cjs
```

يفحص السكربت الإضافة والحذف والاستيراد أثناء التشغيل واستمرارية جهد المكثف عند تبديل المفتاح، دون دعم حسابي مزعوم للشبكات متعددة المكثفات.
